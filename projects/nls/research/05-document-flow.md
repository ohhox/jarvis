# Document Flow — งานสารบรรณโรงเรียน

> Research Date: 2026-04-17

## ภาพรวม

งานสารบรรณ = "งานที่ทำด้วยหนังสือ นับตั้งแต่ คิด ร่าง เขียน พิมพ์ ทำสำเนา ส่ง รับ บันทึก ย่อเรื่อง เสนอ สั่งการ ตอบ เก็บเข้าแฟ้ม และค้นหา"
— ระเบียบสำนักนายกรัฐมนตรี ว่าด้วยงานสารบรรณ พ.ศ. 2526

อยู่ภายใต้ **กลุ่มบริหารทั่วไป** (ฝ่าย 4)

## ประเภทหนังสือราชการในโรงเรียน

| ประเภท | ตัวอย่าง |
|--------|---------|
| หนังสือภายนอก | หนังสือจาก สพท., กระทรวง, หน่วยงานอื่น |
| หนังสือภายใน (บันทึกข้อความ) | ขออนุมัติ, รายงาน, เสนอเรื่อง |
| คำสั่ง | คำสั่งเวรยาม, แต่งตั้ง, จ้าง, ไปราชการ |
| หนังสือเวียน | ระเบียบ, ประกาศ, แจ้งเพื่อทราบ |
| เอกสารวิชาการ | แผนการสอน, SAR, รายงานประเมิน |
| เอกสารการเงิน | ใบเสร็จ, สัญญาจ้าง, ใบส่งมอบงาน |
| หนังสือรับรอง | รับรองเงินเดือน, รับรองสถานภาพ |
| หนังสือสั่งการ (บริกร) | ระเบียบ, ข้อบังคับ |

## Flow A: รับหนังสือเข้า (ปัจจุบัน = กระดาษ)

```

         ▼

│    - ประทับตรารับ        │

         │
         ▼
┌─────────────────────┐

         │
         ▼

## Flow C: หนังสือเวียน

```
ผอ. สั่ง → ธุรการพิมพ์ → ผอ. ลงนาม → ถ่ายสำเนา
→ แจกทุกฝ่าย/ครู → ครูลงชื่อรับทราบ (สมุดเวียน)
```

## Flow D: คำสั่งโรงเรียน

```
ฝ่ายเสนอ → ร่างคำสั่ง → หัวหน้ากลุ่มตรวจ → รอง ผอ. ตรวจ
→ ผอ. ลงนาม → ลงเลขที่คำสั่ง → ประกาศ + แจกจ่าย
```

## ปัญหาปัจจุบัน (กระดาษ)

1. **ช้า** — หนังสือ 1 ฉบับ ผ่าน 4-5 คน ใช้เวลา 1-3 วัน
2. **หาย** — กระดาษหาย ไม่รู้อยู่โต๊ะใคร
3. **ค้นหายาก** — เปิดแฟ้มทีละเล่ม
4. **ซ้ำซ้อน** — ถ่ายเอกสารหลายชุด
5. **ไม่มีสถานะ** — ไม่รู้ว่าหนังสือถึงไหนแล้ว
6. **เก็บไม่ได้** — กระดาษเก่าเปื่อยยุ่ย

## NLS Digital Flow (เปรียบเทียบ)

### รับหนังสือ (Digital)

```
หนังสือเข้า (Email/สพท./scan)
         │
         ▼
┌─────────────────────┐
│ ธุรการ/ครู            │
│ - Upload + OCR       │  ← เลขทะเบียนรับ AUTO
│ - จัดหมวด AI-suggest │  ← 1 นาที
└────────┬──────────────┘
         │ push notification
         ▼
┌─────────────────────┐
│ ผอ.                  │
│ - อ่านบน mobile/web  │  ← ทำทันที ไม่ต้องรอ
│ - กดมอบหมาย → เลือกคน│
│ - พิมพ์/เลือก template│  ← 30 วินาที
└────────┬──────────────┘
         │ auto route
         ▼
┌─────────────────────┐
│ รอง ผอ./หัวหน้ากลุ่ม │
│ - เห็นในกล่องงาน     │  ← notification ทันที
│ - มอบต่อ/ทำเอง      │
└────────┬──────────────┘
         │
         ▼
┌─────────────────────┐
│ ครูผู้รับผิดชอบ       │
│ - notification       │
│ - กด "รับทราบ"       │

         │ auto

## งานธุรการโรงเรียน — สิ่งที่ทำจริงทุกวัน

จาก Pantip + คู่มือปฏิบัติงาน:

1. รับ-ส่งหนังสือราชการ (หลัก)
2. ลงทะเบียนหนังสือเข้า/ออก
3. จัดทำคำสั่ง/บันทึกข้อความ
4. ถ่ายเอกสาร
5. พิมพ์งาน (ครูขอให้พิมพ์)
6. **กรอกข้อมูลระบบ สพฐ: AMSS++, DMC, B-OBEC, SchoolMIS**
7. ดูแลเว็บไซต์โรงเรียน
8. งานอื่นๆ ที่ ผอ. มอบหมาย

**Key Insight:** ธุรการ 1 คนทำทุกอย่าง — NLS ช่วยลดงาน 50-70% ได้ทันที
