# โครงสร้างบริหารโรงเรียน สพฐ

> Research Date: 2026-04-17

## โครงสร้าง 4 ฝ่าย (ตามกฎกระทรวง)

```
                    ┌──────────────────┐
                    │  คณะกรรมการ       │  (ที่ปรึกษา)
                    │  สถานศึกษา        │
                    └────────┬─────────┘
                             │
                    ┌────────┴─────────┐
                    │   ผู้อำนวยการ     │  (ผอ.)
                    │   โรงเรียน        │
                    └────────┬─────────┘
                             │
          ┌──────────┬───────┴───────┬──────────┐
          │          │               │          │
   ┌──────┴──────┐ ┌┴────────────┐ ┌┴────────┐ ┌┴──────────┐
   │ กลุ่มบริหาร │ │ กลุ่มบริหาร │ │ กลุ่ม    │ │ กลุ่มบริหาร│
   │ วิชาการ     │ │ งบประมาณ    │ │ บริหาร   │ │ ทั่วไป    │
   │             │ │             │ │ บุคคล    │ │           │
   └──────┬──────┘ └┬────────────┘ └┬────────┘ └┬──────────┘
          │         │               │           │
    หัวหน้ากลุ่ม  หัวหน้ากลุ่ม    หัวหน้ากลุ่ม  หัวหน้ากลุ่ม
    + ครูในกลุ่ม  + ครูในกลุ่ม    + ครูในกลุ่ม  + ครูในกลุ่ม
```

**หมายเหตุ:** โรงเรียนเล็ก-กลาง ไม่มีรอง ผอ. → ผอ. ดูแลทุกฝ่าย หรือมอบหมาย "หัวหน้ากลุ่ม" (ครูที่ได้รับมอบหมายเพิ่ม)

## สายบังคับบัญชาตามขนาด

### โรงเรียนใหญ่พิเศษ
```
ผอ. → รอง ผอ. (4 คน แต่ละฝ่าย) → หัวหน้ากลุ่ม → ครู
```

### โรงเรียนใหญ่
```
ผอ. → รอง ผอ. (1-2 คน ดูหลายฝ่าย) → หัวหน้ากลุ่ม → ครู
```

### โรงเรียนกลาง
```
ผอ. → หัวหน้ากลุ่ม (ครูที่ได้รับมอบหมาย) → ครู
```

### โรงเรียนเล็ก
```
ผอ. → ครู (ทำทุกอย่างเอง, 2-6 คน)
```

## Key Insight สำหรับ NLS

- NLS Workflow Engine ต้อง **configurable** ตามขนาดโรงเรียน
- โรงเรียนเล็ก: skip รอง ผอ. (ผอ. → ครูตรง)
- โรงเรียนใหญ่: สายอนุมัติยาว (ผอ. → รอง → หัวหน้า → ครู)
- **ทุกโรงเรียนมี 4 ฝ่ายเหมือนกัน** → NLS modules map ได้ครบ
