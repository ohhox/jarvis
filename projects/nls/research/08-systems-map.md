## C. กิจการนักเรียน & ดูแลช่วยเหลือ

> ฝ่าย: ทั่วไป + วิชาการ

| # | ระบบ | รายละเอียด | Phase |
|---|------|-----------|-------|
| C1 | **ระบบดูแลช่วยเหลือ** | SDQ (ดล.1-5), คัดกรอง 4 ด้าน, จำแนกกลุ่ม, ส่งต่อ | Phase 2 |
| C2 | **เยี่ยมบ้าน** | บันทึก, ถ่ายรูป, พิกัด GPS, รายงาน (ส่ง HERO format) | Phase 2 |
| C3 | **วินัยนักเรียน** | บันทึกพฤติกรรม, คะแนนความประพฤติ, แจ้งผู้ปกครอง | Phase 2 |
| C4 | **กิจกรรมพัฒนาผู้เรียน** | ลูกเสือ/เนตรนารี, ชุมนุม, จิตอาสา, ลงทะเบียนกิจกรรม | Phase 3 |
| C5 | **สุขภาพ & อนามัย** | น้ำหนัก/ส่วนสูง, BMI, ประวัติแพ้ยา, ห้องพยาบาล, ส่งต่อ | Phase 3 |
| C6 | **อาหารกลางวัน** | เมนู Thai School Lunch, งบ 22-36 บาท/คน/วัน, รายงาน | Phase 3 |
| C7 | **นมโรงเรียน** | รับนม, บันทึก, รายงาน, ตรวจสอบคุณภาพ | Phase 3 |
| C8 | **รับ-ส่งนักเรียน** | แจ้งผู้ปกครองมารับ, เวลาเข้า-ออกประตู, ความปลอดภัย | Phase 3 |
| C9 | **ผลงาน & รางวัล** | ความสำเร็จ, แข่งขันศิลปหัตถกรรม, ทุนการศึกษา | Phase 3 |
| C10 | **ป้องกันยาเสพติด** | คัดกรอง, ติดตาม, รายงานสารวัตรนักเรียน | Phase 3 |

**SDQ Forms (ระบบดูแลช่วยเหลือ):**
- ดล.1 = ระเบียนสะสม
- ดล.2 = SDQ ฉบับนักเรียนประเมินตนเอง
- ดล.3 = SDQ ฉบับผู้ปกครองประเมิน
- ดล.4 = SDQ ฉบับครูประเมิน
- ดล.5 = แบบบันทึกการเยี่ยมบ้าน
