## เจาะลึกแต่ละราย

### 1. School Bright — ราชาตลาด

- **Website:** schoolbright.co
- **ฟีเจอร์ (20+ modules):**
  - เช็คชื่อ (Face Recognition AI + RFID)
  - วิชาการ: เกรด, สอบออนไลน์, ตรวจข้อสอบ, วิเคราะห์ข้อสอบ
  - การเงิน: จ่ายค่าเทอมออนไลน์, โรงอาหารดิจิทัล
  - กิจการนักเรียน: วินัย, SDQ/EQ, เยี่ยมบ้าน, สุขภาพ
  - ลาออนไลน์, รับ-ส่งนักเรียน, ปฏิทิน, e-Library
  - REGIS (ทะเบียน + อุดหนุน)
- **Hardware:** กล้อง AI, เครื่องสแกน RFID/NFC, ตู้เติมเงิน Kiosk, Smart Canteen
- **จุดอ่อน:**
  - ราคาไม่โปร่งใส (ต่อรองรายโรงเรียน)
  - ผู้ปกครองรู้สึกถูก "บังคับ" ใช้ (Pantip complaints)
  - ไม่เชื่อม SchoolMIS/DMC โดยตรง
  - Hardware lock-in
  - **ไม่มีระบบสารบรรณ**

### 2. iSchoolSIS — ฟรีตลอดชีพ

- **Website:** ischoolsis.com
- **ฟีเจอร์:** ทะเบียน, วิชาการ, กิจการ, บุคลากร, ธุรการ, จ่ายค่าเทอม
- **Tech:** PHP, JavaScript, jQuery, MySQL
- **จุดแข็ง:** ฟรีจริง, ไม่มีค่าติดตั้ง, customize ฟรี
- **จุดอ่อน:** dev คนเดียว, tech เก่า, ไม่มี mobile app, UI เก่า

### 3. Schoolcore — AI-first รายใหม่

- **Website:** schoolcore.co
- **ฟีเจอร์:** Face Recognition, AI Personalized Learning, AI สร้างสื่อ, Chatbot 24/7, จัดตาราง auto, เกรด, การเงิน, ลา
- **จุดแข็ง:** AI เป็น core, แจ้งเตือน SMS/Email/LINE
- **จุดอ่อน:** ใหม่มาก, ฐานลูกค้าน้อย, ไม่มีราคาเปิดเผย

### 4. ZCHOOLMATE — โมเดลต่อหัว

- **Website:** zchoolmate.com
- **Pricing:** ฿100 (Basic) / ฿200 (Standard) / ฿300 (Extended) ต่อนักเรียนต่อปี
- **ฟีเจอร์:** เช็คชื่อ, ลงทะเบียน, รับสมัคร, จ่ายเงิน, แบบสำรวจ
- **จุดอ่อน:** ฐาน ~12 โรงเรียน, หาดใหญ่ (ภาคใต้), ฟีเจอร์น้อย

### 5. BMG Smart Campus — Hardware-first

- **Website:** bmgsofttech.com
- **ฟีเจอร์:** บัตร RFID, Face Recognition AI, โรงอาหารไร้เงินสด, ปพ.5
- **Pricing:** บัตร ฿60/ใบ, ปพ.5 ออนไลน์ ฿4,900/ปี
- **จุดอ่อน:** เน้น hardware, ไม่ใช่ full management system

### 6. Skoolara

- **Website:** skoolara.com
- **ฟีเจอร์:** Student data, Attendance, Payment, Classroom, Calendar, Admin, Announcements, Reports
- **Target:** โรงเรียนนานาชาติ + เอกชน
- **ข้อจำกัด:** ราคาไม่เปิดเผย, เน้นตลาดบน

### 7. SISA Smart (CSN Advance)

- **Website:** csn-advance.com
- **ฟีเจอร์:** วิชาการ, ทะเบียนวัดผล, ประเมิน, บุคลากร, ดูแลช่วยเหลือ, สิทธิ์
- **Pricing:** ~฿30,000 ครั้งเดียว + ติดตั้ง/อบรมฟรี

## Gap Analysis — ช่องว่างที่ไม่มีใครทำ

| Gap | รายละเอียด | ใครทำแล้ว |
|-----|-----------|----------|
| **เชื่อม สพฐ (DMC/SchoolMIS export)** | กรอกครั้งเดียว export ไประบบราชการ | **ไม่มีใคร** |
| **Multi-school dashboard** | เขตพื้นที่ดูภาพรวมทุกโรงเรียน | **ไม่มีใคร** |
| **e-Document/สารบรรณ built-in** | หนังสือราชการ + ระบบโรงเรียน ในที่เดียว | **ไม่มีใคร** |
| **Offline-first** | ทำงานได้แม้เน็ตหลุด | **ไม่มีใคร** |
| **ราคาโปร่งใส + Freemium** | ฟรีจริงสำหรับรัฐ | มีแค่ iSchoolSIS |
| **Open API** | เชื่อม Google Classroom, LINE OA | **ไม่มีใครเปิด API** |
