## DMC — ฐานข้อมูลกลาง

- เป็นระบบเก็บข้อมูลนักเรียนรายบุคคล **เฉพาะโรงเรียนสังกัด สพฐ**
- ใช้ **เลขบัตรประชาชน 13 หลัก** เป็น key
- เชื่อมกับ Smart Card (บัตรประชาชน)
- เก็บข้อมูล 3 รอบ/ปี:
  - รอบ 1: ข้อมูล ณ 10 มิ.ย. (เทอม 1)
  - รอบ 2: ข้อมูล ณ 10 พ.ย. (เทอม 2)
  - รอบ 3: สิ้นปีการศึกษา (จบ/ย้าย)
- **กำหนดจำนวนนักเรียน → คำนวณงบประมาณ** (สำคัญมาก)

## SchoolMIS — เจาะลึก

### ฟังก์ชันหลัก
- บันทึกผลการเรียนรายวิชา (กรอกเกรดทีละคนหรือทั้งห้อง)
- ประเมินคุณลักษณะอันพึงประสงค์
- ประเมินการอ่าน คิดวิเคราะห์ เขียน
- บันทึกกิจกรรมพัฒนาผู้เรียน

### เอกสารที่ออกได้
| เอกสาร | คำอธิบาย |
|--------|----------|
| **ปพ.1** | ระเบียนแสดงผลการเรียน (Transcript) |
| **ปพ.2** | หลักฐานแสดงผลการพัฒนาคุณภาพผู้เรียน |
| **ปพ.3** | แบบรายงานผู้สำเร็จการศึกษา |
| **ปพ.6** | แบบรายงานผลการพัฒนาคุณภาพ |
| **ปพ.7** | ใบรับรองผลการศึกษา |

### Technical
- Web-based: schoolmis.obec.expert
- Login: username/password 8 หลัก + 2FA (Google Authenticator ตั้งแต่ 2568)
- มี backup/restore
- **มีฟังก์ชัน import ข้อมูลจากไฟล์ภายนอกได้** ← สำคัญมาก!
- เชื่อม DMC ผ่านเลขบัตรประชาชน

### Pain Points
- ระบบซับซ้อน ต้องอบรมเฉพาะ
- Sync DMC ↔ SchoolMIS มีปัญหาบ่อย
- ย้ายนักเรียนต้องแก้ข้อมูลด้วยมือ
- ออกเอกสารต้องทำหลายขั้นตอน + ตรวจสอบก่อนพิมพ์

## Pain Map — ครู 1 คนต้องกรอก

```
ข้อมูลนักเรียนเดียวกัน กรอกซ้ำใน:

  DMC         → ข้อมูลส่วนตัว, ที่อยู่, ผู้ปกครอง
  SchoolMIS   → ผลการเรียน, เกรด
  CCT         → ข้อมูลความยากจน (ถ้ามี)
  HERO        → SDQ, คัดกรองจิตใจ
  e-MES       → รายงานตามนโยบาย
  B-OBEC      → ข้อมูลห้องเรียน/อาคาร

  + ระบบโรงเรียนเอง (ถ้ามี เช่น School Bright)
  + Google Classroom
  + LINE กลุ่มผู้ปกครอง

= กรอกข้อมูลซ้ำ 5-8 ที่ ต่อนักเรียน 1 คน!
```

## โอกาสสำหรับ NLS — Export Engine Strategy

### Phase 1 (MVP): สร้างไฟล์ → ครู upload เอง
- SchoolMIS รับ import file ได้ → สร้างไฟล์ถูก format
- DMC → สร้าง CSV/Excel ตาม field ที่ DMC ต้องการ
- ลดงาน 70-80% ทันที
- **ไม่ต้องขออนุญาต สพฐ**

### Phase 2: RPA semi-auto
- ใช้ Playwright/Puppeteer กรอกให้ครูอัตโนมัติ
- เสี่ยงถูกบล็อค แต่ช่วยได้มาก

### Phase 3: MOU กับ สพฐ
- Prove ว่าระบบดี → เสนอ MOU → ได้ API access
- เชื่อมตรง 100%
