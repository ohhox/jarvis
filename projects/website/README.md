# Freelance Website

Static site (HTML/CSS/JS, no build step) with Thai/English toggle.

- Preview: `python3 -m http.server -d . 8000`
- Deploy: GitHub Pages / Netlify / Cloudflare Pages — publish this folder.
- Edit copy: Thai in `index.html`, English in `script.js` (`EN` object).
- Contact form opens the visitor's mail client (`mailto:`). Swap for Formspree/Netlify Forms later for in-page submit.
